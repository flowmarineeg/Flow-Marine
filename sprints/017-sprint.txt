CHANGE 4 — Final Loading: status-based reconciliation (no deletes)
────────────────────────────────────────────────────────────────────────────────

REASON: When doing a Final Loading import, the voyage booking list should reflect
exactly what is in the import file. Instead of deleting, we use status changes:
  - Bookings IN the import → status set to 'Final Loading'
  - Bookings on the voyage NOT in the import → status set to 'Cancelled'
This preserves all records and gives a clear audit trail.

NEW STATUS VALUE:
  Add 'Final Loading' to BOOKING_STATUS enum in constants.js
  This is a terminal operational status meaning the booking is confirmed on manifest

HOW IT WORKS in saveImport():
  Only when importType === 'finalLoading':
  1. Save/update all imported rows as usual (create or update)
  2. After the loop: mark all saved rows with status = 'Final Loading'
     (both newly created AND updated rows)
  3. Collect the booking numbers of all saved rows (created + updated)
  4. Find ALL existing non-deleted bookings for this voyageId that are
     NOT in the saved set
  5. Mark each of those bookings status = 'Cancelled'
     (regardless of current status — they are not on the final manifest)
  6. Return cancelled[] count in the result

RESULT OBJECT CHANGES:
  Before: { created[], updated[], failed[], total }
  After:  { created[], updated[], failed[], markedFinalLoading[], cancelled[], total }
  markedFinalLoading = booking numbers set to 'Final Loading' status
  cancelled = booking numbers set to 'Cancelled' status (not in import)

STATUS TRANSITION NOTE:
  'Final Loading' is a valid destination from Pending and Confirmed
  Bookings already Cancelled or already Final Loading stay as-is in the
  cancelled pass (we just overwrite with 'Cancelled' for non-import ones)
  No invoice guard needed — we are not deleting, just changing status

FRONTEND RESULT CARD CHANGES:
  Show markedFinalLoading count: "5 marked as Final Loading"
  Show cancelled count if > 0: "2 cancelled (not in manifest)"
  Full message example:
    "3 created · 2 updated · 0 failed · 5 marked Final Loading · 2 cancelled"

FINAL LOADING DESCRIPTION UPDATE:
  Banner text:
  "Bookings in this import are marked Final Loading. Existing voyage bookings
   NOT in this file will be Cancelled."
