tracking.service.js — ADD: listEntries()

  listEntries({ page, limit, vesselId, voyageId, serviceId, status, dateFrom, dateTo })

  Query: TrackingHistory with all filters applied
  Sort: lastUpdate DESC
  Populate: voyageId, roundId, vesselId, serviceId, portId, terminalId, createdBy
  Returns: { data[], total }

  This is the backbone of the new tracking list view. It allows filtering by:
    - vesselId      → show only entries for a specific vessel
    - voyageId      → show only entries for a specific voyage
    - serviceId     → show entries for all voyages of a service
    - status        → filter by position status (At Port, Departed, etc.)
    - dateFrom/dateTo → filter by lastUpdate date range

B1. BACKEND — New vessel detail stats endpoint
────────────────────────────────────────────────────────────────────────────────

NEW ENDPOINT: GET /vessels/:id/stats

vessel.service.js — ADD: getVesselStats(id)

  Runs in parallel using Promise.all:

  1. vessel = Vessel.findById(id)

  2. activeRounds = Round.find({ vesselId: id, isDeleted: false })
        .populate('serviceId', 'serviceCode serviceName')
        .sort({ startDate: -1 })
        .limit(20)
     Returns list of all rounds for this vessel

  3. totalRounds = Round.countDocuments({ vesselId: id, isDeleted: false })

  4. voyages = Voyage.find({
       roundId: { $in: activeRounds.map(r => r._id) }
     }).populate('polId podId', 'name code')
       .sort({ etd: -1 })
       .limit(30)
     Returns recent voyages (via rounds)

  5. totalVoyages = count all voyages for this vessel's rounds

  6. bookingStats = Booking.aggregate:
       match: voyageId in vessel's voyage IDs, isDeleted:false
       group: by status → { status, count, totalFreight }
       also: sum all totalFreight (revenue), sum quantity (units booked)

  7. capacityUsed = sum of quantity on Confirmed + 'Final Loading' bookings
       on voyages of ACTIVE rounds of this vessel
       (current live utilisation)

  8. agents = find all unique agentIds from bookings of this vessel's voyages
       Return: [{ agentId, agentCode, agentName, bookingCount }]
       Use Booking.aggregate:
         match voyages, group by agentId, count

  9. recentTracking = TrackingHistory.find({ vesselId: id })
       .populate('portId', 'name code')
       .populate('voyageId', 'voyageNumber')
       .sort({ lastUpdate: -1 })
       .limit(10)
     Latest 10 tracking entries for this vessel

  10. lastPosition = recentTracking[0] (most recent entry)

  RETURNS:
  {
    vessel: { ...all fields },
    stats: {
      totalRounds,    activeRounds (count), completedRounds (count),
      totalVoyages,   activeVoyages (count, status in Scheduled/Departed/In Transit),
      totalBookings,  confirmedBookings, pendingBookings, cancelledBookings,
      totalRevenue,   totalUnitsBooked,
      capacityUsed,   capacityPct (= capacityUsed / vessel.capacity * 100, or null if no capacity),
    },
    rounds:         [...],   // recent rounds list
    voyages:        [...],   // recent voyages list
    agents:         [...],   // agent usage list
    recentTracking: [...],   // last 10 tracking entries
    lastPosition:   {...},   // most recent tracking entry (or null)
  }

vessel.controller.js — ADD: getStats handler

vessel.routes.js — ADD:
  router.get('/:id/stats', rbac('vessels'), ctrl.getStats)
  {MUST be before /:id to avoid shadowing — use explicit /stats/:id pattern}
  Actually use: router.get('/:id/stats', ...) which is fine since Express matches
  routes in order and /stats/... is matched before /:id
