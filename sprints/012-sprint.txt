SPRINT 012 — EXPORT MODULE (Excel & ZIP)
================================================================================

STATUS: ✅ COMPLETE

GOAL:
  Full export capability: every list table exports to Excel, multiple modules
  bundle into ZIP. ExcelJS generates styled workbooks, Archiver handles ZIP.

--------------------------------------------------------------------------------

BACKEND TASKS:
  [x] Rewrote /src/modules/export/export.service.js
        - COLUMNS: complete definitions for all 12 modules:
          vessels, agents, containerTypes, expenseTypes, services, rounds,
          voyages, bookings, expenses, invoices, tracking, auditLogs
        - buildExcelBuffer(moduleName, rows):
            ExcelJS workbook, worksheet per module, styled header row
            (navy #2E4057 background, white bold text, 22px height, frozen)
            Alternating row fill (#FFFFFF / #F8F9FA), thin bottom borders
        - fetchData(moduleName, filters, selectedIds):
            Switch statement — one flat-mapped fetch per module
            All populated refs resolved to human-readable names (no ObjectId in Excel)
            selectedIds filter applied when non-empty
            auditLogs capped at 10,000 rows for safety
        - exportSingle(module, filters, selectedIds) → { buffer, filename, count }
        - exportZip(exports[], res) → streams Archiver ZIP to response

  [x] Updated /src/modules/export/export.controller.js
        - Uses ALLOWED_MODULES from service (derived from COLUMNS keys)
        - POST /export/excel: validates module, calls exportSingle, streams xlsx
        - POST /export/zip: validates each module in array, calls exportZip
        - X-Export-Count response header for client toast message

NOTES:

  - auditLogs export hard-capped at 10,000 rows
  - ZIP uses archiver with zlib level 9 compression
  - Single-module export skips ZIP and downloads Excel directly
