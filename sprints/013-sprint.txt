================================================================================
SPRINT 013 — UI/UX IMPROVEMENTS & MASTER DATA ENHANCEMENTS
================================================================================

STATUS: ⏳ Pending

GOAL:
  Refine master data modules based on business requirements:
  rename vessel capacity field, enforce IMO as required, add ownership
  description; make agent code optional with dynamic multi-row contacts;
  remove container type description from view/form; add custom expense
  categories; add agent field to route legs.

--------------------------------------------------------------------------------
CHANGES SUMMARY (6 modules affected)
--------------------------------------------------------------------------------

  1. VESSELS         — rename teuCapacity→capacity, IMO required, ownership description
  2. AGENTS          — agentCode optional, contacts become multi-row dynamic array
  3. CONTAINER TYPES — remove description from list table and create/edit form
  4. EXPENSE TYPES   — custom category: user can type new category or pick existing
  5. ROUTE LEGS      — add agentId field to each leg (Country→City→Port→Terminal→Agent)
  6. SEED            — update seed data to reflect all schema changes

  CT description:  field kept in DB, removed from UI only
  ET category:     required string, any value (no enum), max 50 chars
  Leg agentId:     optional MongoId
