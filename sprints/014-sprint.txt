────────────────────────────────────────────────────────────────────────────────
A1. ROUND P&L REPORT  (/reports/round-pnl)
────────────────────────────────────────────────────────────────────────────────

ROOT CAUSE:
  The round dropdown calls roundsService.list({ limit: 200 }) but the response
  shape is { data: { data: [...], pagination: {...} } } — the component accesses
  r.data.data directly which works, BUT the rounds list items have serviceId as
  a populated object { _id, serviceCode } only if the backend populates it.
  Check: round.service.js list() — does it populate serviceId?
  If not, serviceCode shows as undefined in the dropdown label.

  More critically: the "Run Report" never fires because roundId comes from the
  dropdown but the query is enabled:!!roundId — if roundId = '' it never runs.
  When a round IS selected the query runs but the response data path may be
  wrong: r.data.data vs r.data (depends on responseHelper shape).

FIXES NEEDED:
  Backend:
  [x] round.service.js list(): add .populate('serviceId', 'serviceCode serviceName')
      so dropdown shows correct service codes

  Frontend RoundPnlReport.jsx:
  [x] Fix rounds query: roundsService.list returns { data: { data, pagination } }
      → rounds = roundsData?.data || roundsData || []
      (currently roundsData || [] — misses the nested .data)
  [x] Fix report query response path:
      reportsService.getRoundPnL().then(r => r.data.data) — verify this matches
      responseHelper which returns { success, data, message }
      → r.data.data is correct if data wraps the payload
  [x] Fix: when roundId changes, reset stale data (add key prop or use enabled+refetch)
  [x] Add P&L Bar Chart: Revenue vs Expenses side-by-side bars using Chart.js
      Labels: expense categories. Datasets: Revenue (teal), Expenses (red)
  [x] Fix stat cards: expenseTotals may have multiple currencies — show all,
      not just USD hardcoded
  [x] Loading state: show spinner while isFetching (not just isLoading)
      because after first load, re-selecting a round shows stale data

────────────────────────────────────────────────────────────────────────────────
A2. VOYAGE PERFORMANCE REPORT  (/reports/voyage-performance)
────────────────────────────────────────────────────────────────────────────────

ROOT CAUSE:
  "Run Report" button sets run=true but the useQuery enabled:run means it fires
  ONCE. If user changes filters and clicks "Run Report" again, the query already
  ran — enabled is still true but queryKey hasn't changed so it won't refetch.
  The user must change a filter value for a re-fetch to happen.

  Second issue: rounds dropdown filters by serviceId:
    (rdData || []).filter(r => !serviceId || String(r.serviceId?._id || r.serviceId) === serviceId)
  But rdData?.data is the actual array (same nested shape issue as above).

FIXES NEEDED:
  Frontend VoyagePerformanceReport.jsx:
  [x] Fix rounds data access: rdData?.data || rdData || []
  [x] Fix "Run Report": change pattern — use refetch() instead of enabled flag:
      const { data, isLoading, refetch } = useQuery({ enabled: false, ... })
      <button onClick={() => refetch()}>Run Report</button>
      This way every click fires a fresh request regardless of filter changes.
  [x] Add Chart: horizontal bar chart of top 10 voyages by totalFreight
      (Chart.js Bar, indexAxis: 'y', sorted descending)
  [x] Status badge chips in table (coloured by status)
  [x] Show "0 bookings" rows differently (dim text) vs rows with bookings

────────────────────────────────────────────────────────────────────────────────
A3. REVENUE REPORT  (/reports/revenue)
────────────────────────────────────────────────────────────────────────────────

ROOT CAUSE:

  Also: when no date filter set and no serviceId, the report may return ALL
  voyages ever — which is a huge query with no feedback during loading.
  The loading spinner is shown but fullPage spinner breaks layout.

FIXES NEEDED:

  [x] Fix LoadingSpinner: use inline spinner (not fullPage) so layout stays stable
  [x] Add Doughnut/Pie Chart: revenue share by service using Chart.js Doughnut
      Each slice = one service, labelled with serviceCode
  [x] Add trend indicator on each row: revenue share % of grand total
      shown as a thin progress bar under the revenue value
  [x] Grand total row styling: bolder, teal background tint

B1. NEW BACKEND DASHBOARD ENDPOINT
────────────────────────────────────────────────────────────────────────────────

  NEW FILE: /backend/src/modules/dashboard/dashboard.service.js
    Single function getDashboardStats() running parallel queries:

    KPI Counts (Promise.all):
      activeVessels:      Vessel.countDocuments({ status:'Active', isDeleted:false })
      activeRounds:       Round.countDocuments({ status:'Active', isDeleted:false })
      plannedRounds:      Round.countDocuments({ status:'Planned', isDeleted:false })
      totalVoyages:       Voyage.countDocuments({})
      activeVoyages:      Voyage.countDocuments({ status:{ $in:['Scheduled','Departed','In Transit'] } })
      totalBookings:      Booking.countDocuments({ isDeleted:false })
      confirmedBookings:  Booking.countDocuments({ status:'Confirmed', isDeleted:false })
      pendingBookings:    Booking.countDocuments({ status:'Pending', isDeleted:false })
      totalAgents:        Agent.countDocuments({ status:'Active', isDeleted:false })
      draftInvoices:      Invoice.countDocuments({ status:'Draft', isDeleted:false })
      overdueInvoices:    Invoice.countDocuments({ status:'Overdue', isDeleted:false })
      paidInvoices:       Invoice.countDocuments({ status:'Paid', isDeleted:false })

    Revenue Summary (last 30 days):
      Booking.aggregate: sum totalFreight for Confirmed non-deleted bookings
      in last 30 days

    Revenue by Service (for pie chart):
      Booking → group by voyageId → join voyage → group by serviceId → sum totalFreight
      Top 6 services

    Bookings by Status (for doughnut):
      Booking.aggregate: $group by status, $sum: 1

    Monthly Booking Trend (last 6 months, for line chart):
      Booking.aggregate: $group by { year: $year, month: $month }, $sum totalFreight, $sum count
      Returns 6 data points

    Voyage Status Distribution (for doughnut):
      Voyage.aggregate: $group by status, $sum: 1

    Recent Activity (last 10 mutations from AuditLog):
      AuditLog.find({}).sort({ timestamp: -1 }).limit(10)
      .populate('userId', 'name')

  NEW FILE: /backend/src/modules/dashboard/dashboard.controller.js
    Single handler: getStats

  NEW FILE: /backend/src/modules/dashboard/dashboard.routes.js
    GET /dashboard/stats → auth → ctrl.getStats

  Register in server.js: app.use('/api/v1/dashboard', require(...))
