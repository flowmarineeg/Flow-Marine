BACKEND TASKS:
  [x] Create /src/modules/reports/reports.service.js
        5 functions, each a focused aggregation pipeline:

        getRoundPnL({ roundId }):
          - Finds round, populates service + vessel
          - Revenue: Booking aggregate — sum totalFreight (non-cancelled) for round's voyageIds
          - Expenses: Expense aggregate — matches roundId OR voyageId IN voyageIds
            $lookup expensetypes → $group by { category, currency }
          - Returns: round info, voyageCount, bookingCount, totalRevenue,
            expenseTotals { USD: n, EUR: n }, expenseBreakdown[]

        getVoyagePerformance({ voyageId, serviceId, roundId, status, dateFrom, dateTo }):
          - $lookup bookings (correlated sub-pipeline) → $group bookingCount, totalFreight, totalSlots, totalQty
          - $lookup rounds, services, ports (POL/POD)
          - Returns: rows[] + totals (aggregated across all rows)

        getBookingReport({ voyageId, agentId, status, serviceId, dateFrom, dateTo }):
          - Filters bookings with full populate
          - Runs separate summary aggregate for totals (non-cancelled only)
          - Returns: rows[], total count, summary { totalFreight, totalQty, totalSlots, count }

        getRevenueReport({ serviceId, dateFrom, dateTo }):
          - Matches voyages, correlated $lookup bookings, $group by serviceId
          - Returns: rows[] sorted by totalRevenue DESC, grandTotal

        getExpenseReport({ category, expenseTypeId, roundId, voyageId, dateFrom, dateTo, currency }):
          - Finds expenses with populate, filters category post-populate
          - Builds summary map: group by { category, currency } → total, count
          - Returns: rows[], summary[]

  - Round P&L auto-loads on round selection (single-round query is fast)
